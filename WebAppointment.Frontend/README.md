## Teknolojiler

- **Next.js 16**
- **React 19**
- **Tailwind CSS 4**
- **TypeScript**

## Kurulum ve Çalıştırma

1. **Gereksinimler:**
   - Node.js (18.17.0 veya üzeri önerilir)

2. **Bağımlılıkları Yükleme:**
   Terminali `WebAppointment.Frontend` klasöründe açın ve komutu çalıştırın:
   ```bash
   npm install
   ```

3. **Geliştirme Sunucusunu Başlatma:**
   ```bash
   npm run dev
   ```

Uygulama varsayılan olarak `http://localhost:3000` adresinde çalışacaktır.

## Build (Production)

Prodüksiyon sürümü almak için:
```bash
npm run build
npm start
```
